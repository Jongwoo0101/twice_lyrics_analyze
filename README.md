# 🎵 Twice Lyrics Analysis  
**2025학년도 2학년 2학기 전공선택 — 응용머신러닝 기말 프로젝트**
(https://www.kaggle.com/code/wonjongwoo/twice-song-analysis)

---

##  프로젝트 개요

본 프로젝트는 **트와이스(TWICE)의 한국어 타이틀곡 가사를 분석하여 멤버별 가사 특징을 파악하고, 단어 사용 패턴을 데이터 기반으로 해석**하는 것을 목표로 한다.  
텍스트 마이닝 기법과 연관 규칙 분석(Apriori)을 적용하여 다음과 같은 분석을 수행하였다.

##  분석 방법

### 1) **NLTK 기반 단어 빈도 분석**
- 불용어 제거(stopwords)
- 토큰화(tokenization)
- 고빈도 단어 추출
- WordCloud 및 Bar Plot을 활용한 시각화

### 2) **Apriori 알고리즘 기반 멤버별 가사 패턴 분석**
- 각 멤버의 파트에서 등장하는 단어들을 아이템셋으로 구성  
- 지지도(Support), 신뢰도(Confidence), 향상도(Lift)를 기준으로  
  **“특정 단어 → 특정 멤버”** 연관 규칙을 계산  
- 멤버별 특징 단어 및 가사 스타일 해석

---

##  프로젝트 목표 요약

- 트와이스 가사에서 **멤버별 언어적 특징**을 도출
- 연관 규칙 분석을 활용하여  
  **각 멤버가 자주 부르는 단어 패턴**을 정량적으로 파악
- 전체 가사 흐름 속에서 핵심 키워드 및 컨셉 트렌드 시각화
